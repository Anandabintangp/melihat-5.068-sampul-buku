# Melihat 5.068 Sampul Buku

Situs scrollytelling dan dashboard interaktif untuk esai Ananda Bintang Purwaramdhona.

## Publikasi
Target GitHub Pages: `https://anandabintangp.github.io/melihat-5.068-sampul-buku/`

## Data
- `data/data.csv`: snapshot data publikasi
- `data/summary.json`: agregasi untuk visual
- `data/books.min.json`: metadata ringkas Jelajah Buku

## Pengujian lokal
```powershell
py -m http.server 8000
```
Buka `http://localhost:8000/`.
